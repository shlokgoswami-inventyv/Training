## 01 - Logic Building

Flowchart-based logic exercises covering fundamentals like factorial, number series, patterns, and Taylor series expansion.

---

## 02 - HTML & CSS

A company landing page with a login/register form, built with HTML and CSS.

---

## 03 - SQL Queries

SQL query practice on a movie database — covers joins, subqueries, grouping, and more.

---

## 04 - JavaScript Tasks

JavaScript tasks practicing arrays, Symbols, spread operator, and Promises.

---

## 05 - Exercism JavaScript

30 solved exercises from the [Exercism JavaScript track](https://exercism.org/tracks/javascript), covering functions, arrays, closures, destructuring, promises, regex, classes, and more.

## 06 - Rust

Rust learning projects organized by topic, managed as a Cargo workspace.

| Folder | Description |
|--------|-------------|
| `01_loops` | Conditionals (`if/else`), `loop`, `while`, and labeled loops (`'outer`) |
| `02_struct` | Structs, `impl` blocks, and methods |
| `03_serde` | Serialization and deserialization using the `serde` crate |
| `04_Mutex` | Thread-safe shared state using `Mutex` |
| `05_Rwlock` | Reader-writer locks (`RwLock`) for concurrent access |
| `06_Packages_and_Modules` | Rust module system and code organization |
| `07_Hashmap_and_Hashset` | `HashMap` and `HashSet` collection types |
| `Generics` | Generic types and functions |
| `inventory` | An inventory management system project |
| `multithreading` | Multi-threaded programming concepts |
| `ownership_and_borrowing` | Ownership rules, borrowing, references, and lifetimes |
| `server` | A CRUD REST API for users built with **Axum**, **Tokio**, **serde**, and **uuid** — runs on `http://127.0.0.1:4500` |
